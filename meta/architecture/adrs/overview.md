# Architecture Decision Records

<!-- purpose
A log of significant architectural decisions: what was decided, why, and what alternatives were rejected. Each record captures the context that made the decision necessary, the options considered, the rationale for the chosen approach, and the known trade-offs accepted.

Each ADR should be a short, self-contained document. A common structure is: status (proposed, accepted, deprecated, superseded), context, decision, and consequences. See [template.md](template.md) for the convention used in this repo.

See [here](https://raw.githubusercontent.com/architecture-decision-record/architecture-decision-record/refs/heads/main/README.md) for a longer discussion of ADRs and examples.

If the decision explains an unmovable constraint rather than a deliberate choice, consult [constraints/](../constraints/overview.md) to see if it better fits there. If the decision establishes a recurring pattern, also capture it in [conventions/](../conventions/overview.md).
-->
