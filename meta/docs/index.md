# Docs

<!-- purpose
Product-facing documentation for individual features or areas of the product. One file per feature or product area.

Each file describes a specific feature or user experience: what it does, what the experience is like, and why it exists. Write as if explaining the feature to someone who will use it, not someone who will build it. Do not describe internal architecture, implementation details, data models, or system components.

Only create a file here if it describes a concrete, named feature or user-facing experience. Do not create files for general topics, system properties, or anything that isn't a distinct thing a user can interact with.

If it describes the product as a whole rather than a specific feature, consult [overview](../overview.md) to see if it better fits there. If it is a design document for a planned change, consult [specs/](../specs/overview.md) instead.
-->
